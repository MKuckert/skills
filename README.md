# Skills

A collection of agent skills (`SKILL.md`-based) for coding agents such as Claude Code, Codex, pi and others.

## Installation

Install via the [`skills`](https://www.npmjs.com/package/skills) CLI:

```bash
npx skills add https://github.com/MKuckert/skills
```

## Available skills

| Skill | Description |
| --- | --- |
| [`experiment-design`](experiment-design/SKILL.md) | Helps formulate experiments (e.g. A/B tests, pilots, hypothesis checks) along a structured template: setup, changed variables, hypotheses, counter-hypotheses, evaluation and execution. Turns unstructured brain dumps into the template. *(German)* |
